# Todo React Avançado

Aplicação de gerenciamento de tarefas de alta performance desenvolvida em React, estruturada com componentes limpos, Context API e estilização moderna em Tailwind CSS com tema tecnológico 3D.

## 🚀 Tecnologias Utilizadas

* **React (Vite)**
* **Context API & Hooks**
* **Tailwind CSS**
* **JavaScript (ES6+)**
